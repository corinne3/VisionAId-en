# Per-device calibrations

> English translation of the team's [`config/calib/README.md`](../../config/calib/README.md).

Files generated by `uv run python -m visionaid.apps.calibrate_phone` (see [`checkpoint_recordings.md`](checkpoint_recordings.md)):

- `<phone.device>_camera.yaml`: K, distortion, image size, reprojection error;
- `<phone.device>_imu.yaml`: `R_cam_imu`, gyroscope bias, image ↔ IMU time offset, unit correction.

They are loaded automatically (`visionaid.calib.device`). Without a file, `intrinsics.hfov_deg` and the prior values of `body` are used.
